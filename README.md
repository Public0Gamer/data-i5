# Data i5 - Autonomous Real-Time Lead & Client Hunting SaaS

**Data i5** is a high-speed, enterprise-grade autonomous B2B client hunting and extraction system. It discovers real, verified businesses across any niche and location worldwide with real-time contact details (Phone, Email, Official Website, Physical Address, and Google Maps Profiles).

---

## 🚀 Key Features

1. **Dead-Simple 2-Field Interface:**
   - **Target Niche / Industry** (e.g. `Digital Marketing`, `Plumbers`, `Dentists`, `Real Estate`, `Hospitals`)
   - **Target Location / City** (e.g. `Jaipur`, `Miami`, `London`, `Dubai`, `Tokyo`)

2. **Zero Dummy Data Guarantee:**
   - Never serves static files or fake placeholder data (`+1 555...`).
   - Every lead is scraped live on-demand with multi-tier real-time extraction (DuckDuckGo Lite Lynx Engine + OpenStreetMap Nominatim).

3. **Autonomous Website Contact Crawler:**
   - Directly crawls the official website of discovered businesses in parallel.
   - Extracts verified `tel:` links, `mailto:` addresses, and phone numbers in under 4 seconds.

4. **1-Click Communication:**
   - 💬 **WhatsApp Direct Chat** with pre-filled intro message.
   - 📞 **Direct Click-to-Call** for instant outreach.
   - 🌐 **Official Website** direct access.
   - 🗺️ **Google Maps Profile** link for location verification.

5. **Dynamic Intelligent Pagination:**
   - Displays 12 to 15 businesses per batch.
   - "Load More" appears strictly when additional leads exist in that location.

6. **1-Click Commercial CSV Export:**
   - Export all discovered leads into standard CSV formatted for CRM importation.

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Server
```bash
node server.js
```

### 3. Open in Browser
Open `http://localhost:4000` in your web browser.
